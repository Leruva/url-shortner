# URL Shortner
This project is a URL Shortener web application that converts long URLs into short, shareable links.
The application supports creating, redirecting, updating, and deleting shortened URLs, along with tracking how many times a short link has been accessed. A lightweight frontend is served directly through the backend for seamless interaction.
## Tech Stack
Backend - Node.js, Express.js, MongoDB<br>
Frontend - HTML, CSS, JS<br>
Tools & Utility - REST APIs , Express Middleware, Git and Github
